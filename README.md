# 🐾 Pet Pals: Magic Match (React Native + Expo)

A world-class, tactile Match-3 puzzle mobile and web game crafted specially for **kids aged 5 to 10**, featuring rich geometric match patterns, an intense physics explosion engine, procedural audio, and a storybook playground UI!

---

## 🌟 What's New & Unique

### 1. 🧩 Beyond 3, 4, 5: Rich Geometric Match Patterns
- 🐝 **2×2 Square Match ("Pet Nest") ➔ Bumblebee Copter**:
  - Matching 4 identical animal friends in a 2×2 box spawns a fuzzy Bumblebee with a spinning rotor propeller!
  - When swapped or matched, it takes flight with a whirring buzz, flies to an obstacle or random tile, and pops it!
- 🍯 **T-Shape & L-Shape ➔ Honey Splash Pot**:
  - Intersecting perpendicular matches spawn a clay honey pot that triggers a double 3×3 golden honey explosion!
- ⭐ **Cross (+) Shape ➔ Star Wand**:
  - 4-way intersections spawn a hazel Star Wand that fires diagonal cosmic 'X' ray beams slicing across both diagonals of the entire board!
- 👑 **6+ in a Line ➔ Royal Crown**:
  - A rare mega-match spawning an ornate 5-spire crown that clears **two entire animal species at once**!
- 🎊 **4 in a Line ➔ Party Confetti Popper**: Row or Column blast with festive streamers.
- 🌈 **5 in a Line ➔ Rainbow Butterfly**: Clears all friends of the chosen species with a stardust shower.

---

### 2. 💥 High-Impact Kinetic Explosions & Juice
- **120ms White-Hot Radial Flash**: Optical flash bloom bursting at the detonation center.
- **28–42 High-Velocity Sparks**: Realistic air drag deceleration, fountain lift, and parabolic gravity arcs.
- **4 Distinct Particle Elements**: Golden starlight diamonds, bouncy candy strawberries, species-colored paw sparks, and 3D fluttering pennants.
- **Expanding Dual Shockwave Rings**: Neon aura and razor-sharp starlight rings slicing across the board.
- **Damped Sinusoidal Spring Screen Shake**: Real physical camera vibration rattling the board container translationally and rotationally.
- **Floating Bouncy Score Pills**: Badges springing up with tags like `SUPER POP!`, `HONEY SPLASH!`, and `+120!`.

---

### 3. 🎨 Storybook Playground Station UI
- **Hanging Canopy Header**: Overhead tree branch with twisted hemp ropes suspending carved wooden signboards that sway gently in the breeze.
- **3D Golden Paw Moves Badge**: Sculpted 4-toed golden paw with an inlaid cabochon jewel chamber that shifts to a pulsing ruby glow when moves run low.
- **Woven Wicker Berry Basket**: An artisanal woven basket that dynamically fills with wild strawberries, featuring 3 golden star pegs that pop up as score milestones are reached.
- **Carved Hardwood Recess Board**: Individual router-carved sockets with deep chiseled bevels and warm oak/walnut checker tiles.

---

### 4. 🎵 Deep Procedural Audio Synthesizer
- Sub-bass explosion thump (150Hz -> 35Hz with analog-style soft-clipping saturation).
- Whirring Bee Copter propeller buzz with comedic cartoon pop.
- Diagonal Star Wand laser shimmer with sparkling cosmic bells.
- Regal Royal Crown trumpet fanfare with 6-voice golden major triad.
- Ascending pentatonic marimba scale cascades.
- Soft wooden tap pops and cute bear cub giggles.

## 🚀 Quick Start

### 1. Play in Web Browser
```bash
npx expo start --web
```
or
```bash
npm run web
```

### 2. Play on Mobile (iOS & Android)
1. Open the free **Expo Go** app on your phone.
2. Run `npx expo start` and scan the QR code!

### 3. Run Automated Tests
```bash
npm test
```
